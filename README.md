# Marvin

## Requisitos

- [Node.js](https://nodejs.org/) 20 o superior (incluye npm)
- Git

## Instalación

```bash
git clone https://github.com/migux97/Marvin.git
cd Marvin/frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abrir http://localhost:5173 en el navegador.

Para generar la versión de producción y verla localmente:

```bash
npm run build
npm run preview
```
